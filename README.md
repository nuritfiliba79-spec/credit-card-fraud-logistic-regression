# Credit Card Fraud Detection — Logistic Regression Dashboard

דשבורד HTML אינטראקטיבי שמציג מודל **רגרסיה לוגיסטית** לחיזוי הסיכוי שעסקת כרטיס אשראי היא הונאה.

## הנתונים

`credit_card_fraud_10k (1).csv` — 10,000 עסקאות, מתוכן **151 הונאות (1.51%)**, כלומר הנתונים **לא מאוזנים**.

| עמודה | תיאור |
|---|---|
| `amount` | סכום העסקה |
| `transaction_hour` | שעת העסקה (0–23) |
| `merchant_category` | קטגוריית בית העסק (Electronics, Travel, Grocery, Food, Clothing) |
| `foreign_transaction` | עסקה בחו"ל (0/1) |
| `location_mismatch` | אי-התאמת מיקום (0/1) |
| `device_trust_score` | ציון אמון במכשיר (0–100) |
| `velocity_last_24h` | מספר עסקאות ב-24 השעות האחרונות |
| `cardholder_age` | גיל בעל הכרטיס |
| `is_fraud` | **משתנה המטרה** (1 = הונאה) |

## שיטה

1. **חלוקה אקראית 80% Train / 20% Test**, מרובדת (`stratify=y`) כדי ששיעור ההונאות יהיה זהה בשתי הקבוצות (`random_state=42`).
2. **עיבוד מקדים:** `StandardScaler` למשתנים המספריים ו-`OneHotEncoder` לקטגוריית בית העסק.
3. **טיפול בחוסר האיזון:** `LogisticRegression(class_weight="balanced")`. כל הונאה מקבלת משקל גבוה פי ~65 מעסקה תקינה, כך שהמודל לא "מתעלם" מהמחלקה הנדירה.
4. **השוואה** למודל רגיל ללא שקלול מחלקות.
5. **הערכה על נתוני ה-Test בלבד** לפי Recall, Precision, F1 ו-ROC AUC (ובנוסף PR AUC).

## תוצאות (Test, סף 0.5)

| מדד | מודל מאוזן | מודל רגיל |
|---|---|---|
| **Recall** | **0.967** | 0.600 |
| Precision | 0.259 | 0.750 |
| F1 Score | 0.408 | 0.667 |
| **ROC AUC** | **0.993** | 0.995 |
| PR AUC | 0.736 | 0.824 |
| הונאות שנתפסו | **29 / 30** | 18 / 30 |
| התראות שווא | 83 | 6 |

**פרשנות:** בזיהוי הונאות, פספוס הונאה (FN) יקר בהרבה מהתראת שווא (FP). המודל המאוזן תופס 29 מתוך 30 הונאות, במחיר של 83 התראות שווא מתוך 1,970 עסקאות תקינות (כ-4%). המודל הרגיל מדויק יותר, אבל מפספס 40% מההונאות. ROC AUC של כ-0.99 מראה ששני המודלים מפרידים היטב בין המחלקות, וההבדל ביניהם הוא בעיקר מיקום הסף.

בדשבורד יש **מחוון סף** שמחשב מחדש את כל המדדים ואת מטריצת הבלבול, כדי לבחור את האיזון בין Recall ל-Precision. הסף שממקסם F1 במודל המאוזן הוא ~0.99 (Recall 0.667, Precision 0.714, F1 0.690).

**המשתנים החזקים ביותר:** ציון אמון נמוך במכשיר, שעות לילה, ריבוי עסקאות ב-24 שעות, אי-התאמת מיקום ועסקה בחו"ל.

## מה יש בדשבורד

- כרטיסי KPI: Recall, Precision, F1, ROC AUC
- מחוון סף החלטה עם עדכון חי
- עקומת ROC (מאוזן מול רגיל)
- גרף Precision / Recall / F1 לפי סף
- מטריצת בלבול
- טבלת השוואה בין המודלים
- גרף מקדמי המודל
- טופס חיזוי לעסקה חדשה, שמחשב את ההסתברות בדפדפן לפי מקדמי המודל
- תמיכה במצב כהה ובהיר
